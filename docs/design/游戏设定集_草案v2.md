## 一、核心定位与不可动摇原则

> **一句话说清 v2 是什么**：  
> 一款**零数值成长、纯能力与次数驱动的 FPS 离散回合互坑对抗游戏**——每回合全员先在 60° 全息沙盘里同屏抢机关、共造越来越疯癫的立体机关竞技场，再在密闭面板盲选动作/武器/防具与魔改词条，最后从外围起跑带俯冲扎进第一人称战场，一边笑骂损友的阴间机关、一边见招拆招决出胜负。

1. **核心原则（继承 v1 `01`｜铁律）**：游戏不包含任何「加数值」的成长机制（无攻击力、防御力、血量上限、移速等数值强化）。全场仅围绕两类核心资源运转：**次数**（身体受击、防具耐久、机关触发次数，均可耗尽）与**能力**（动作、武器、防具功能、跨载体改造词条）。
2. **开黑氛围**：主打**「一边笑骂“你放的什么阴间机关”一边见招拆招」**的轻竞技脑洞互坑，兼顾高光操作爽感与朋友开黑节目效果。
3. **人数包容**：一套统一状态机同时包容 **1v1 宿敌局**、**2v2 搭档局** 与 **3~4 人自由混战（FFA）**。
4. **视角锁定**：实战严格锁定 **FPS 第一人称视角**；战备（放陷阱、盲选构筑、外环选入场位）统一复用 **60° 露天全息沙盘视角**，通过 `0.7~1s` 无滚转俯冲无缝衔接。
5. **信息博弈（继承 v1 `12`）**：全程不公开敌方配置面板与血条，读懂对手 Build 与残甲状态全靠 FPS 强剪影外显与实战交锋观察。

## 二、整体对局流程、顺序选项与人数自适应

### 1. 大回合宏观循环

整场对局精准控制在 **5~7 轮造图 / 6~8 分钟**；每大回合战备硬上限 **≤ 26 秒**，实战占比稳定在 **55%~65%**：

```text
大回合循环（地图机关跨回合留存，每回合初重装次数）：
  ┌─ 战备 A｜沙盘同屏抢盲盒 & 锚点放陷阱（13s = 4s 抢盒 + 9s 落子）
  │     ↕（A / B 顺序可按大厅选项配置，共用同一沙盘机位零割裂）
  └─ 战备 B｜全息盲选构筑 / 词条改造（10s，首轮 14s）
        ↓
  3s 外环起跑带同步盲选入场位（中/内圈机关区红区禁降，杜绝空降跳关）
        ↓
  0.7~1s 无滚转俯冲切入 FPS（2s 线框高亮本回合新增机关）
        ↓
  FPS 立体死斗（20~45s；含中央大喇叭破局 & 两段式流血缩圈）
        ↓
  3s「损友归因标牌」喜剧播报 & 计分结算 → 进入下一大回合
```

### 2. 环节顺序：3 套明确选项（零额外开发成本）

因密闭构筑（原 `03`）改由在虚化 60° 沙盘背景上直接弹半透明盲选面板实现，不切物理房间，两种顺序可共用一套状态机与机位无缝切换：

| 选项 | 环节顺序 | 开黑心理战差异 | 优劣权衡与定位 |
| :--- | :--- | :--- | :--- |
| **选项 1（推荐默认）** | **放陷阱（明）→ 构筑/改造（暗）→ 外环入场 FPS** | **“先一起出阴间考题，再各自偷写奇葩答卷”**。进局第 1 秒直接抢盒笑骂破冰，随后对着刚落定的新地形精准换装/配词条；可故意放假机关钓鱼诱导对手选错装备 | 100% 护住规则 `12`（零泄密）、治愈首轮盲猜、换装不吃瘪；**作为默认标准顺序** |
| **选项 2** | **构筑/改造（暗）→ 放陷阱（明）→ 外环入场 FPS** | **“揣着秘密底牌抢盒子 + 语音狼人杀诈胡”**。边抢盒边互相审讯猜出装（“你死抢滑油是不是拿了远程弩？”），把读人前置到嘴炮博弈 | 嘴炮整活气氛极强；但选放机关易提前泄密，且先换装后可能被盒子里的克制机关反伤 |
| **选项 3（大厅开关）** | **房主一键热切选项 1 / 2**（附带「每回合随机顺序」整活模式） | 仅调整状态机两段指针，零额外制作成本；满足不同开黑车队偏好，也便于灰盒阶段直接 A/B 实测 | **强烈建议直接做进房间自定义规则** |

### 3. 人数自适应（一套循环覆盖 1v1 / 2v2 / 3~4P）

| 模式 | 单大回合命数 | 计分与胜负条件 | 核心设计意图 |
| :--- | :--- | :--- | :--- |
| **1v1 宿敌局** | **小局 BO3（先拿 2 杀赢下本大回合）**<br>*小杀间不造图，3s 外环盲选重入并刷新血/甲/场上机关次数* | 每大回合胜者 `+1` 胜点，**先拿 4 胜点夺冠**（4~7 大回合） | 彻底根治 1v1 短 TTK“造图比打架久”的节奏硬伤；同一套新机关图连打 2~3 命，可在同回合内读懂对手新词条并换外环路线反杀 |
| **2v2 搭档局** | **1 命团灭制** | 存活队 `+1` 胜点，**先拿 5 胜点夺冠**（同归于尽平局 `+0`，直接加造一轮图） | 4 人交锋天然撑满 30~45s；双人用机关配合夹击节目效果拉满 |
| **3~4 人混战（FFA）** | **1 命大逃杀（Last Man Standing）** | **类《超级鸡马》多元积分条，先满 10 分夺冠**（5~7 大回合）：<br>• 回合存活吃鸡：`+2 分`<br>• 亲手击杀：`+1 分/人`<br>• **「阴间机关助攻」**：`+1 分`（对手触发**你放的机关**后 3s 内阵亡，每回合限 1 次）<br>• 全员同归于尽：全员 `+0 分` 触发吐槽彩蛋 | ① 击杀分打击纯躲角落的渔翁；② **机关助攻分**让 5 秒先死的人依然死盯战局看谁踩进自己布的坑，观战秒变押注看乐子 |

## 三、构筑、改造与防滚雪球经济

### 1. 基础构筑三大类（严守零数值，全机制功能化）

- **动作（3 选 1，机制化而非加移速）**：
  - **跑（战术滑铲）**：低姿高速滑铲，可钻过腰高绊线或半开铁闸。
  - **跳（二段跳 / 蹬墙跳）**：纵向突进与跨越地面机关，配手脚入镜动画增强 FPS 跑酷感。
  - **爬（自动抓墙翻越 Mantle）**：贴墙攀爬高台并可短暂挂墙偷瞄。
- **武器（3 选 1）**：
  - **剑**：配 `1.5~2m` 轻度前冲吸附 + 宽水平挥砍扇面（防 FPS 贴脸空刀），挥剑可快速劈碎/排空机关次数。
  - **弩**：中远距精准单发弹道，适合远程点射触发/破坏机关。
  - **枪**：中近距干脆爆发，适合压制与快速破甲。
- **防具（4 选 1，共享 3 点耐久且赋予专属功能）**：
  - **盾牌**：举盾正面格挡弹道、投掷物与拳套击飞（每次格挡扣 1 耐久）。
  - **鞋子**：防滑防夹战靴，踩中破甲铁夹时免疫定身（仅扣 1 耐久），并减轻滑油失控。
  - **帽子 / 胸甲**：围绕功能特化扩展（如防头顶高空压制/视野干扰，或扩展受击反制窗口，严守零数值原则）。

### 2. 改造点经济：保底成长 + 败者反超（杜绝滚雪球）

- **第 1 回合**：全员 **`0` 点起步**（沿用 v1 `05`），白板三大类入场。
- **第 2 回合起（每大回合结算发放，与陷阱 100% 解耦）**：
  - **本轮最高分 / 胜者**：**`+1` 改造点**（保住赢家正反馈，每轮都能给 Build 加料）。
  - **其余玩家 / 败者**：**`+2` 改造点**（内置 *ROUNDS* 式橡胶筋追赶；4P 严格按**本回合总得分排名**发，防拿 3 杀排第 2 又白嫖 `+2` 点）。
  - **「首死倒霉蛋」安慰彩蛋（3~4P 专属）**：本轮最先阵亡且 0 击杀者，下回合获得**抢盲盒提前 `1.5s` 起跑权**。

### 3. 个人词条槽、败者免费换装与跨载体变形（升级 v1 `24 / 25`）

- **废除 v1 `25` 的清空改造惩罚**：在开黑互坑定位下，换武器清零改造会抑制见招拆招的乐趣。
- **5 词条槽上限**：每次改造固定花 `1` 点，已购词条存入个人词条槽（上限 5 槽防后期膨胀；满槽后可花 `1` 点覆盖旧词条）。
- **换装权与跨载体自动变形（全面激活 v1 `24`）**：
  - 每回合构筑阶段，**败者可免费更换 1 件基础装**（动作/武器/防具三选一）；**胜者若想换装须花 `1` 点**（防止胜者无成本变脸架空跨局读人 `12`）；全员若想 3 件大洗牌统一花 `1` 点。
  - 更换基础装后，**已拥有的词条自动按新载体变形生效**：
    - 例：**「连发」**落在剑上 = 三连光弧疾风斩，换成弩 = 三连弩，换成枪 = 双连发爆发；
    - 例：**「投掷」**落在剑上 = 旋转飞剑（插墙可远程引爆远处机关），落在盾上 = 投掷回旋盾；
    - 例：**「震荡波」**（由原规则 `11` 范围圈弹开升格为主动词条）：落在「跳」上 = 落地重踏爆发范围击退波，落在「盾牌」上 = 格挡反震弹开周围敌人——让玩家能在中圈机关最密集的地方主动把对手弹进滑油、推板或大拳套！

## 四、地图三层结构与「外环起跑带」入场机制

为根治“全图任意空降直接跳过所有路径陷阱”的致命缺陷，同时保住 0.7 秒俯冲进 FPS 的仪式感与防堵门底线，竞技场采用**三层同心箱庭结构**（基准尺寸 `24m × 24m`，露天 2~2.5 层，严禁大面积封顶房，天桥投影 `< 20%`）：

```text
┌────────────────────────────────────────────────────────┐
│ 最外圈｜外环起跑带（8 个外围入场位 · 绿色安全环 · 绝对禁放陷阱） │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 中圈｜机关修罗场（20~28 个战术锚点 · 红色禁降区）      │  │
│  │      楼梯 / 门框 / 墙角 / 二楼桥面 —— 必须双脚趟过！   │  │
│  │     ┌──────────────────────────────────────┐     │  │
│  │     │ 内核｜中心高台 & 聚光灯舞台（必争制高点）  │     │  │
│  │     │      （缩圈终点 · 同样属于红色禁降区）    │     │  │
│  │     └──────────────────────────────────────┘     │  │
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

### 外环入场 4 条铁律
1. **彻底废除「胜者先选落位（原 `09`）」与「全图任意空降（原 `10`）」**：全员在 3 秒入场阶段只能在**最外圈 8 个入场位**中同步盲选 1 个，中圈与内核高台全部标红禁止空降——**谁也无法从天而降逃课绕开陷阱**。
2. **选入口即战术反制，零堵复活点**：外环绝对禁放陷阱，彻底杜绝堵门；若对手把东门外铺成地狱，玩家可主动挑北门/西门切入找薄弱点。
3. **无须复杂落地无敌补丁**：因外环无机关，删去多余的“落地无敌免疫陷阱”规则；若两人在外环选了同一个点，落地触发防重叠小推力将两人分别弹向左右相邻通道，各走各路不白吃亏。
4. **0.7~1s 战地式俯冲进 FPS**：倒计时归零后，镜头沿平滑曲线从 60° 沙盘无滚转（`Roll=0`）俯冲扎入第一人称身体，自动对齐面朝中场的安全朝向，并在落地前 **2 秒半透明线框高亮本回合新增机关**，建立瞬时空间记忆。

## 五、「放地图陷阱」派对交互与 10 大 FPS 脑洞机关库

### 1. 沙盘派对交互规则（13s = 4s 抢盒 + 9s 锚点落子）

- **60° 玩具沙盘镜头（FOV 38°）**：仅允许 `Q/E` 按 90° 切换 4 个预设观察角防止迷路；鼠标悬停在天桥下方时，上层自动半透明线框剖切且射线穿透命中下层锚点。
- **4s 同屏物理抢盲盒**：沙盘中央砸开公用盲盒弹出 **`人数 + 2`** 个立体机关模型（1v1 出 4 件，4P 出 6 件）。全员操控**带碰撞体积的彩色 3D 全息抓手**同屏互撞疯抢（超时自动分配 1 件防挂机）。
- **9s「拎雷比划」+ 预设战术锚点（Sockets）一键落子**：
  - 全图预设 20~28 个经策划静态验证连通性的分类锚点（地面/门框/墙面/高台缘），选件后只亮兼容槽，悬停磁吸、右键 90° 转向、左键“咚”一声砸落——2~3 秒完成操作，彻底根治 3D 堵死与穿模。
  - **开黑笑点**：全员手里拎着机关到处比划的彩色半透明虚影**全场实时可见**（可打快捷激光标/表情吓唬朋友）；两人同时点同一槽位时，先落者锁定、晚一步者抓手“哐当”弹开。
- **跨回合生命周期与软上限**：
  - 单回合内，每个机关带 **1~3 次触发/破坏次数**，耗尽即本小局碎裂失效（实战可用武器/卖盾主动拆局）。
  - 回合结束（含 1v1 BO3 小杀间隔），未被拆迁炸弹永久摧毁的机关**保留在地图上并重装次数**，实现场地逐轮升级演化。
  - **软上限防垃圾场**：1v1 上限 `10` 个 / 4P 上限 `14` 个；超限后最早放置的老机关生锈冒烟，下回合次数耗尽即**永久报废腾位**。

### 2. 3 张常驻派对搞事卡（混入公共盲盒池）

| 派对卡 | 效果与开黑价值 |
| :--- | :--- |
| **拆迁大炸弹** | 落点引爆并**永久炸毁目标旧机关及邻格 1 个机关**，专治上回合最恶心的阴间连招 |
| **扳手搬家卡** | 不放新雷，直接把场上任意已有旧机关**拧转 90° 或搬去新锚点**（把朋友的弹簧板拧成朝内坑他自己） |
| **问号盲盒机关** | 部署时全场只见大问号，开战后首次触发/受击时随机揭晓为**纯物理整活机关**（随机池**剔除**激光柱，守住零暗雷底线） |

### 3. FPS 专属 10 大零数值机关库（100% 敌我不分 · 严格 `Roll=0` 防晕）

全机关标配**齐膝~齐腰垂直发光锚点** + 5m 待机机械声 + **0.25~0.35s 咔哒闪红前摇**（除拳套 0.5s、激光柱 0.8s），90% 为纯造局杠杆，绝不设静默瞬秒暗雷：

| 类别 | 机关（单回合次数） | FPS 视听与非数值能力（守 `01`） | 与动作 / 武器 / 防具 / 改造的化学反应 |
| :--- | :--- | :--- | :--- |
| **物理喜剧** | **1. 墙面大拳套**（3次） | 转角墙面；0.5s 弹簧压缩“咔哒”声后横向巨拳轰飞，零伤害 | 举「盾牌」扣 1 耐久可抗飞反冲；远射拳套提前排空次数；把卡点老六轰下高台 |
| **物理喜剧** | **2. 超滑香蕉冰砖**（3次） | 零镜头倾斜，改用屏幕冰霜速度线+“哧溜”声，剥夺急停转向与「爬」抓握 | 「剑（连发）」借势打搞笑高速滑铲斩；贴墙专克爬墙党 |

## 六、FPS 战斗结算、防晕读人与反龟缩机制

### 1. 战斗与状态结算（闭环原 `P0-01~07`）
- **防具优先全挡（拍板 `P0-03 / P0-05`）**：防具全局共享 **3 点耐久**，优先完全抵挡未闪避的攻击或格挡；破甲后才开始计算身体受击，确保单回合 5~6 次有效交锋落在 `20~40s` 黄金 FPS 手感区间。
- **2 击流血与终结（拍板 `P0-02`）**：身体承受 **2 次有效命中**后进入**流血状态**，持续降至 1 血（一碰即死），再受 1 次任意有效攻击判负（若滞留缩圈外，则由心跳倒计时直接处决）。
- **击杀重置状态反渔翁（强化原 `18`）**：实战中击杀对手的瞬间，胜者立刻**清空流血、回满 2 击容错并补满防具耐久**，彻底杜绝多人混战中躲角落捡残血漏的渔翁行为。
- **回合结束重置边界（拍板 `P0-04`）**：每大回合开战全员重置血量/流血/防具耐久，**保留**已装词条、剩余改造点与场上持久化机关。

### 2. FPS 专属 4 道体验护甲
1. **防晕 3D 镜头铁律**：任何机关位移只改物理速度向量，严禁强旋转玩家鼠标朝向或翻滚屏幕。
2. **实战一眼读人外显（保 `12`）**：改造词条长在武器模型上（多重荧光箭匣、双层剑影、回旋尾环），防具 3 耐久穿在身上逐级碎裂（完好发光 → 裂纹冒星 → 急促闪红 → 当场爆甲飞碎片），动作配醒目部位剪影（抓钩手套、弹簧气囊踝、风纹护膝）。
3. **2 秒「损友归因标牌」**：被连环机关坑死时定格播报罪魁祸首链路（如：`被 [老王的香蕉冰砖] 送上 [阿强的拳套] 撞进 [小李的连发弩]`），把挫折秒变笑点。
4. **多人先死者「整活观战幽灵」**：先死玩家秒变活人不可见的浮空表情幽灵，带 2 个 5s CD 零伤害整活技能——① 给 6 秒不动的老六头顶砸**荧光嘲讽番茄**（全图暴露方位帮大家抓老六）；② 给场上机关点**大笑假警报音效**吓唬活人。配合 45s 硬缩圈（每死 1 人提速 5s），彻底消灭观战坐牢感。

### 3. 反龟缩双段舞台（替代《超级鸡马》“共同终点旗”）
- **开战 20 秒｜中央【聚光灯大喇叭】**（沙盘期高亮位置，天然把全员陷阱重心吸引到中央动线；**不直接加分**）：任意玩家读条 3 秒踩亮，立刻触发**「全员聚光灯抓老六」**（所有对手头顶亮起 6 秒空中探照灯柱，不显面板）并**提前引爆缩圈**。
- **开战 35 秒（1v1 BO3 小局 35s；4P 45s 且每死 1 人提速 5s）｜「两段式零数值流血缩圈」**：
  - **段 1（3 秒宽容）**：跨出圈外仅红雾警报，允许利用圈外弹射垫/爬墙绕后秀操作；
  - **段 2（补齐 1 血流血处决闭环）**：圈外滞留满 3 秒直接无视防具打入规则 `16` 流血态（降至 1 血）；仍不进圈则头顶开启 **5 秒心跳倒计时，归零直接判「失血淘汰」**（回圈暂停倒计时）。
