## 一、核心原则

- **01｜零数值成长，纯能力驱动**  
  游戏不包含任何「加数值」的成长机制，所有变化均表现为**能力**的获得与改变。不存在攻击力、防御力、生命上限、移动速度等数值强化；改造换取的永远是「**能做什么**」，而非「**数值强多少**」。  
  整场对局仅围绕两类核心资源运转：**次数**（可消耗、会耗尽）与**能力**（可执行的行为）。

## 二、对局流程

- **02** 玩家点击「开始对局」。
- **03** 双方各自进入独立的密闭空间进行构筑，彼此隔离、互不可见。
- **04** 构筑分为三大类：**动作 / 武器 / 防具**。
- **05** 初始构筑阶段默认不进行改造，且不持有任何改造点数（0 点起步）。
- **06** 构筑完成后双方进入对战地图；入场即处于可交战状态，既可以被攻击，也可以直接反击。
- **07** 改造点数仅在发生击杀后才开始产出。
- **08** 每次阵亡后，败者从以下两项中二选一：**重新构筑**，或**沿用上次配置**。
- **09** 胜者在击败对手后获得一段缓冲时间，期间可自由移动并选择站位。
- **10** 败者可在小地图上任意选点复活（覆盖全图任意位置）。
- **11** 败者复活时会产生一个范围圈，将附近的玩家弹开。
- **12** 对局全程不通过配置面板公开对手出装，败者需要依靠实战交手时的观察与思考，自行判断对手的构筑。

### 流程速览

```text
开始对局
  → 双方各自进入密闭空间，构筑三大类（动作 / 武器 / 防具，0 点起步、无改造）
  → 进入地图（入场即可双向交战）
  → 首次击杀 → 开始产出改造点数
  → 对局中：每次击败 +2 点 / 每次改造 -1 点
  → 阵亡分支：
      ├── 胜者：+2 点、重置所有状态、一段时间内自由选择站位
      └── 败者：重新构筑（已获改造清零） / 沿用上次配置
                → 小地图全图任意选点复活 → 范围圈弹开附近玩家
  → 继续对局
```

## 三、构筑内容

- **13｜动作**（示例，非穷举）：跑、跳、爬。
- **14｜武器**：弩、剑、枪。
- **15｜防具**：帽子、盾牌、胸甲、鞋子。

---

## 四、战斗与生命

- **16** 每名角色最多承受 **2 次**攻击，随后即进入**流血状态**，生命值持续下降直至仅剩 1 滴血。
- **17** 防具同样仅拥有 **3 点耐久**。
- **18** 击败对手的一方（胜者）将**重置所有状态**。

---

## 五、改造系统

- **19｜改造对象**：覆盖武器、防具、基础能力（动作）全部三大类。
- **20｜改造资源**：改造点数。
- **21｜点数产出**：每击败对手一次，获得 **2 点**。
- **22｜点数消耗**：每次改造固定消耗 **1 点**。
- **23｜产出时机**：开局为 0 点，仅在发生击杀后才开始产出。
- **24｜改造示例**：
  - **剑** → 获得「投掷」能力
  - **弩** → 获得「连发」能力
  - 同一词条落在不同载体上会产生对应变化：例如「连发」落在**剑**上，表现为**连续挥击**
  - 也可获得「投掷」能力*（具体主语归属待定，见第七节 `P1-10`）*
- **25｜重构惩罚与博弈意图**：  
  阵亡后选择「重新构筑」时，此前已获得的改造全部清零、不予保留。  
  > **设计意图**：这是对失败方施加的明确惩罚；但同时也赋予败者重新构筑一套针对性配置的翻盘机会——而这份针对必须依靠自己在实战中读出的判断，而非系统直接给的确定情报。

## 六、规则速查

> 本节仅由上述已确认设定直接汇总得出，不包含新增规则。

| 维度 | 核心规则 |
| :--- | :--- |
| **点数经济** | 开局 `0` 点 / 每次击败 `+2` 点 / 每次改造 `-1` 点 → **1 次击败 = 2 次改造** |
| **能力原则** | 所有改造换取的均为能力变化，不包含任何数值强化 |
| **生命与状态** | 身体承受 2 次命中 → 进入流血 → 降至 1 血；防具拥有 3 点耐久；击败方重置所有状态 |
| **信息博弈** | 全程不公开配置面板，读懂对手 Build 完全依靠实战观察与推演 |
| **复活机制** | 配置二选一（重构 / 沿用），全图任意选点复活，落地范围圈清场弹开附近玩家 |
