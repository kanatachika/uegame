## 1. 这游戏到底好玩在哪

聊完三轮之后，它已经不是一款“能配装的普通射击游戏”了，玩法经历了三次升级：

1. **第一轮**：开局掷骰子拿点数 → 买动作装身上 → 开打。
2. **第二轮**：打起来之后还能继续合成、死后掉能力、杀人赚点数，整局都在变化。
3. **第三轮**：身体不同部位装不同能力，打哪儿坏哪儿；地图本身也产出点数，成了必争之地。

说白了，这游戏的核心不再只是“瞄准开枪”，而是 **一边打架、一边抢地图资源，同时不断拆掉对手的身体、修补和改装自己的身体**。  
如果要用一句话形容它的类型：**一款 1v1、带部位破坏、边打边变的肉鸽夺宝射击游戏**。

它最抓人的三个特点：

1. **改装的是“怎么动”，不是“拿什么枪”**：别人比枪械配件，我们比谁会跳、会爬、会滑铲。
2. **打不同部位会直接废掉对应能力**：普通 FPS 打腿只是扣点血或减点速；在这里，打腿是直接把对方的“跑步”能力打掉一格。
3. **身体不是一成不变的**：打着打着能买新能力、合出更强的能力，也会被打坏、死后随机掉没。如果身上的能力全掉光了，就会被打回开局“只能转头看和慢慢走”的惨状，首尾呼应。

## 2. 一局游戏的基本框架

### 【已确认】（编号对应第 7 章的速查表）

- **1**：用 Unreal Engine 5（UE5）开发，第一人称射击（FPS）。
- **2**：开局掷骰子拿点数，用点数给角色买各种能力模块。
- **3**：角色出生时几乎是个白板，默认只能“转视角看”和“走路”。
- **5**：1v1 单挑模式。

> **【推论】**（由第 8 条“杀对手一次加 2 点”推出来）：一局应该有好几条命，不是死一次就直接结束（具体几条命待定）。

### 【建议 · 目前未采纳】

- **公平掷骰**：两个人拿同样的点数，骰子不决定谁钱多，而是决定“这局商店卖哪些模块”或者“地图开哪几条路”，这样既随机又公平。
- **每局换池子**：每局随机轮换一部分模块和配方，避免大家永远只玩那一套最强搭配。
- **多局制与 Ban 位**：打三局两胜（BO3）或五局三胜（BO5），每小局重新掷骰子配能力；上一局输的人可以禁掉对方一个模块，当做让分。
- **隐藏配装**：互相看不到对方装了什么（最多只显示对方总点数），得靠听脚步声、看移速和扬尘来猜对手买了啥。
- **防止死局的保底规则**：比如给一把免费但很弱的基础手枪，或者加上占点计时 / 倒计时，防止两个人都光买跑跳不买攻击手段，谁也打不死谁。
- **让掷骰子更有参与感**：用实体物理骰子，双方都能看见，还能花点数重掷或者抢先掷，让“看运气”变成可以博弈的环节。
- **限时选配**：开局只给 20 秒暗选配装，避免选太久把 1v1 的快节奏拖垮。

## 3. 点数怎么来、怎么花

**点数能干嘛**：买基础模块、做合成；以后如果采纳【建议】，还能拿来修模块、重掷骰子或者花钱侦察对手。

点数有 4 个来源，对应 4 种完全不同的玩法。玩家同一时间只能干一件事，所以整局都在纠结“现在是去打架、去守点，还是去捡钱”：

| 点数来源 | 特点 | 鼓励玩家做什么 | 状态 |
| :--- | :--- | :--- | :--- |
| 开局掷骰子 | 开局一次性给、看运气 | 决定开局怎么搭能力 | 【已确认 2】 |
| 击杀对手（+2 点） | 打架赢了立刻拿大额收益 | 主动找人交火 | 【已确认 8】 |
| 占领据点 | 占得越久给得越多 | 守住关键区域运营 | 【已确认 10】 |
| 地图散落拾取 | 随机刷在地上、谁先到归谁 | 规划路线满图跑 | 【已确认 11】 |

- **【已确认 8】击杀对手一条命，奖励 2 点。**
  - **定价参考（建议保留）**：如果一个基础模块卖 1~2 点，那杀一次给的 2 点刚好够再买两个基础模块合一次新的。这样“杀人 → 合成 → 变强 → 再杀人”的节奏会特别顺。
  - **玩法变化**：因为打起来之后还能不停赚点数，这游戏就不再是“开局买完定终身”，而是整局都在不停发育和变形。
- **【已确认 10】占点给点**：按占领时间持续发放点数。
- **【已确认 11】捡点**：地图上会随机刷出可拾取的点数。

> **一个很妙的连锁反应**：  
> 因为占点和捡点也能拿点数，所以“不打架也能变强”成了可行路线。哪怕你全买移速、跳跃，一把枪都不买，也能靠跑图捡点和偷点把自己养肥。这正好解决了第一轮担心的“不买攻击能力就会卡死”的问题——1v1 不再只是拼枪法，而是两个人抢同一张地图的资源。

**打赢一次的差距**：赢的人赚 2 点，输的人还会随机掉 1 个模块，里外里单次交手大概拉开 3 点的差距。

## 4. 模块系统

### 4.1 角色初始状态与模块分类

- **【已确认 3】** 初始角色只会“看”和“走路”。
- **【已确认 4】** 可以花点数买的动作模块，比如：跑步、跳跃、攀爬、滑铲。
- **【已确认 6】** 模块分成两档：
  - **基础模块**：直接花点数买，也是用来合成的材料。
  - **组合新模块**：拿基础模块合出来的；如果正好凑对了固定配方，会合出带名字的强力模块。

**【建议 · 目前未采纳】以后可以扩展的模块类型**：

| 类型 | 可以做的具体能力 |
| :--- | :--- |
| 侦察与信息 | 透视对手一个模块槽、制造假跑步声、放大对方脚步声 |
| 防御与保护 | 给某个槽位上保险（死了不掉）、加护甲或防磨损镀层 |
| 维修 | 花点数修好被打残的模块 |
| 火力与枪械 | 连发、开镜瞄准（ADS）、换弹、稳枪（控后坐力）、副武器 |
| 兜底攻击 | 免费但伤害很低的基础射击（防止没人买枪，见第 2 章） |

> 如果以后采纳“隐藏配装”，侦察类模块会特别好玩：要么花点数直接买情报，要么故意开枪试探但暴露自己位置，两边各有代价。

### 4.2 合成规则

- **【已确认 6】有固定配方**：按配方把对应模块合在一起，能出更强的新模块。
- **【已确认 6】随便怎么合都能出东西**：不管拿哪几个模块往一起合，都不会失败、不会报废。

> **【待确认的理解】配方用来追上限，不是用来卡人的**：  
> 没凑对配方时，不是出垃圾或纯随机，而是合出一个弱化版的“杂交模块”——比如跑步加跳跃没对上配方，就合出个“半速跑 + 半高跳”的凑合技能。  
> 这样既能让老玩家研究和背配方追求强力组合，又不至于让新手乱合一场把点数全打水漂。

### 4.3 装在身上不同部位、打哪儿坏哪儿

- **【已确认 9】** 模块要装在身体对应部位上，每个模块有 3 点耐久；对手打中你哪个部位，那个部位上的模块就掉 1 点耐久（打中一次扣 1 点）。

**这会带来三个很好玩的战术变化**：

- **瞄哪儿比单纯打准更重要**：比如专打对手的腿，把他的“跳跃”打废，他就上不了高台。枪法从“打得准”变成了“懂怎么拆对手的配装”。
- **打一枪就能试出对手买了啥**：照腿打一枪，看有没有掉耐久提示，就能猜出对方买没买腿部能力，和隐藏配装配合起来非常有意思。
- **能力损坏是个渐变过程**：先是被打得 3 → 2 → 1 → 0 失效，死了再随机掉一块。不会让人觉得莫名其妙突然被惩罚，而是“身体一直被打烂”的自然结果。

### 4.4 模块怎么丢

- **【已确认 7】** 角色死亡时，身上会**随机消失**一个模块。注意是直接消失，**不会**掉给杀你的人。
  - **玩起来的感觉**：打着打着配装会变样，你得临场应变——“完了，我突然不会跳了，接下来怎么打？”
  - **好处**：赢家抢不走你的能力，滚雪球没那么夸张（不过赢家还是拿了 2 点，实际会不会滚雪球还得测试）。
  - **戏剧感**：如果一路输到模块掉光，又会变回开局“只能看和走”的原始人状态。
- **【建议 · 目前未采纳】** 死了随机掉模块时，优先从已经掉过耐久的模块里抽，这样“被打坏”和“死了掉”在直觉上更统一。

**小结**：失去模块的路径是连续的——被打掉耐久 → 归零失效 → 死亡随机少一个 → 退回白板。

## 5. 地图怎么配合这套玩法

### 【建议 · 目前未采纳，但和核心设定非常搭】

地图不该只是个摆掩体的场地，而应该让玩家“买的能力能直接换成地形优势”：

| 地图地形 | 对应的能力价值 |
| :--- | :--- |
| 高台 | 只有买了“跳”或“攀爬”才上得去 |
| 矮缝 / 洞口 | 只有买了“滑铲”才钻得过去 |
| 长直道 | 买了“跑”才能快速抢占或脱战 |
| 多层立交结构 | 买了“攀爬”能绕出第三条奇袭路线 |

把这个和 **【已确认 10/11】的占点、散落点数** 结合起来就更爽了：把据点放高台上，把散落点数塞在矮缝里——那**买一个“跳”或“滑铲”，不只是买个动作，而是直接买了一条赚钱路线**，一举两得。

另外也可以让开局的骰子决定这局哪几条路开、哪几条路封，逼着玩家先看地图再决定买什么能力。

## 6. 一局游戏从头到尾怎么走

按时间顺序串起来，一局游戏大概是这样：

1. **T0 开局掷骰**：掷出这局的点数；【建议】顺便决定这局开放哪些模块和路线。
2. **T1 选配装**：花点数买基础模块或直接合成；【建议】限时 20 秒暗选，只公开总点数。
3. **T2 出生**：默认只会看和走；【建议】附带一把很弱的保底手枪。
4. **T3 核心对局循环**（整场游戏最好玩的部分）：
   - 两边去抢点、满图捡点数、碰面交火
   - 打中对方某个部位 → 对应模块耐久 -1 → 归零失效
   - 杀掉对手：赢家拿 2 点，马上可以补买新能力或做合成
   - 被打死：随机少一个模块，复活后配装已经变了
   - 整局下来，双方的能力一直在变，每条命的打法都在调整
5. **T4 单局结束**：某一方命用光了，或者占点进度满了。
6. **T5 局间调整【建议】**：重掷骰子、重新配装、输方禁掉一个模块。
7. **T6 总结算【建议】**：按 BO3 / BO5 决出最终胜负。

**一句话总结核心循环**：

```text
掷骰子拿点 → 买基础能力 → 合成变强 → 打架杀人再拿 2 点 → 继续合
与此同时：被打坏部位、死一次随机少一个能力 → 逼着两边不断换打法
```

**最值得留意的一条连锁反应**：

```text
打废对手的腿 → 他跑不动、跳不上去 → 抢不到据点也捡不到散落点 → 没钱买新模块 → 越来越弱
```

> 所以这游戏打的不是谁血条厚，而是谁能打断对方的赚钱链条。

## 8. 还没拍板的问题清单（按主题和轻重缓急整理）

> **优先级说明**：  
> - `P0`：不敲定就没法做可玩原型  
> - `P1`：直接影响手感和平衡，得尽快想清楚  
> - `P2`：细节玩法，可以后面再定

### A. 受击和部位耐久（最急的一块）

| 编号 | 优先级 | 要决定的问题 |
| :---: | :---: | :--- |
| A1 | `P0` | **同一部位装好几个能力，打中了扣谁的？** 比如跑、跳、滑铲都在腿上，打中腿扣哪个？可选方案：按顺序轮流扣 / 把腿细分（小腿=跑、膝盖=跳、大腿=滑铲）/ **让玩家自己决定把模块挂在身体哪个部位**（最推荐，玩家可以把贵的“跳”藏在不好打的后背，多一层博弈）。 |
| A2 | `P0` | **打中没装模块的空部位怎么算？** 必须有兜底规则（比如直接扣基础血量），不然玩家全装在手上，打腿完全没伤害就成漏洞了。 |
| A3 | `P0` | **“打中一次扣 1 点”怎么算？** 霰弹枪一喷好几颗弹丸，或者高射速冲锋枪突突三下，是不是瞬间就把一个模块打废了？这是目前最大的平衡隐患。 |
| A4 | `P1` | **合出来的新模块有几点耐久？** 还是 3 点，还是把材料的耐久加起来？被打烂之后是直接没了，还是退回成基础模块？ |
| A5 | `P1` | **耐久打到 0 是暂时用不了，还是永久报废？** 能不能花点数修？修是不是比重新买便宜？（如果能修，顺便还能出维修、护甲类模块） |
| A6 | `P1` | **3 点耐久会不会太脆？** 结合多命制来看，要不要改成不同武器扣不同耐久（比如轻武器扣 1，重武器扣 2）。 |

### B. 点数与经济

| 编号 | 优先级 | 要决定的问题 |
| :---: | :---: | :--- |
| B1 | `P0` | 一局总共几条命？点数有没有上限？开局 + 击杀 + 占点 + 捡点全加起来，中后期会不会钱多到把全身插满？ |
| B2 | `P0` | 每个基础模块具体卖几点？得算清楚“杀一次给 2 点”能不能稳定撑起一次合成。 |
| B3 | `P1` | 杀对手赚的 2 点什么时候能花？复活时再花、随时打开面板花，还是可以攒着？能不能带到下一条命或下一小局？ |
| B4 | `P1` | 占点给点的速度是多少？必须人一直站在圈里才给，还是占下来之后就算离开也持续给？被打断后进度会不会清零或衰减？ |
| B5 | `P1` | 地上的散落点数怎么刷？定时刷、随机刷，还是捡走后过几秒再刷？双方地图上都能看见吗？能不能守株待兔？捡东西需不需要买“手”模块？ |
| B6 | `P1` | 会不会出现“两边谁也不打架，各跑各的捡点数”的无聊局面？得保证杀人收益不比纯捡钱差，或者让散落点数越到后面越少。 |
| B7 | `P2` | 需不需要给劣势方一点低保（比如连死两次多给 1 点），防止雪球越滚越大？ |

### C. 合成系统

| 编号 | 优先级 | 要决定的问题 |
| :---: | :---: | :--- |
| C1 | `P0` | 没凑对配方时具体合出什么？是半吊子杂交能力、残缺版，还是退还成随机基础模块？ |

## 9. UE5 开发备忘（给程序参考）

- **直接上 GAS 最省事**：把每个模块做成一个 `GameplayAbility`（再带点属性修改）。装模块就是 `GiveAbility`，卸下来或打掉了就是 `ClearAbility`。
- **合成做成配表**：本质就是删掉 N 个旧技能、给 1 个新技能。配方放进 `DataTable` 或 `DataAsset`（填好“哪些材料 → 出哪个技能”），以后策划改配方不用动代码。
- **部位耐久怎么做**：把角色的受击碰撞盒按部位分组，对应到各自的模块槽位；打中回调里直接扣对应模块的耐久。耐久数据放在服务器端维护。
- **白板角色**：自定义一个最精简的 `Pawn`，把默认 `Character` 自带的跳、蹲、冲刺全关掉，后面买到哪个能力再给哪个。
- **联网防作弊**：身上装了哪些模块（ID 数组）、每个模块剩几点耐久、当前有多少点数，全由服务器说了算再同步（replicate）给客户端；合成、掉落、扣耐久必须在服务器结算，客户端只管预测和播动画。
- **随机可回放**：死亡随机掉哪个模块，用“服务器随机种子 + 当前回合数”来算，方便以后做回放和排查争议。
- **别上来就铺太大**：先做个最小灰盒原型验证核心乐趣——只做 **跑、跳、基础枪** 3 个基础模块 + **1 条合成配方** + **部位耐久** + **1 个据点**，先试试“打坏、合成、掉落”这三件事放一起好不好玩，好玩了再往里加几十个模块。

## 10. 潜在风险清单

| 编号 | 风险程度 | 可能会踩的坑 & 应对思路 |
| :---: | :---: | :--- |
| R1 | **高** | **滚雪球太狠**：赢的人拿 2 点，输的人少 1 个模块，而且耐久还一直在掉，劣势方可能越打越残完全翻不了盘 → 做完灰盒第一件事就测这个。 |
| R2 | **高** | **高射速武器和霰弹枪破坏平衡**：如果“打中一下扣 1 点”不加限制（见 A3），喷子一枪或冲锋枪扫半秒就能把模块打烂，耐久系统就废了。 |
| R3 | **中** | **开局掷骰子存在感变低**：打着打着又能赚点数、死了又会掉能力，开局怎么分配点数可能变得没那么重要，要实测节奏。 |
| R4 | **中** | **配方被背烂后套路固化**：大家很快就会算出唯一最优解 → 建议每局随机换一部分可用配方。 |
| R5 | **中** | **上手门槛不低**：又是打部位、又是合成、又是随机掉，规则不少 → UI 必须一眼就能看清自己和对手身体各部位还剩什么能力。 |
| R6 | **中** | **随机掉能力让人觉得委屈**：掉模块虽然刺激，但玩家可能会觉得“我操作没问题，纯属运气差变残了”，要注意反馈和心理预期。 |
| R7 | **中** | **满地随机刷点太看脸**：如果散落点纯随机刷在对手脸上，会盖过配装策略 → 建议刷新点固定可预判，只随机给多少点。 |
| R8 | **低** | **合成界面拖慢节奏**：如果每次合成都要打开一个复杂菜单，1v1 节奏会断掉 → 建议用快捷轮盘、限时选配，或者只在复活时操作。 |
| R9 | **低** | **开局点数太少直接想退**：低点数开局得有“虽然穷但专精一招也能打”的出路，不能让玩家掷出个小点数就绝望。 |
