# 技术架构与模块文档（预留目录）

这里是《点数 / DICEBODY》后续存放 **UE5 技术设计、系统实现说明与前后端同步约定** 的地方。

## 当前状态

目前项目处于玩法演进与仓库基建期，尚未创建 `.uproject` 工程（当前主推灰盒验证方案见 [游戏设定集（草案 v2）](../design/游戏设定集_草案v2.md)，原始规则基线见 [游戏设定集（成品 v1）](../design/游戏设定集_成品v1.md)）。

等 v2 草案确认并正式启动 2 周 UE5 FPS 开黑灰盒原型（Greybox）时，我们会在这里陆续补充以下文档：

- **双视角与三层箱庭架构**：60° 露天沙盘镜头（天桥悬停剖切、同屏物理抢盒抓手）↔ `0.7~1s` 无滚转俯冲切入 FPS；外环 8 入口禁雷区 + 中圈 24 个 `ATrapSocket` 预设战术锚点。
- **零数值能力与跨载体词条架构**：动作（滑铲/二段跳/爬墙）、武器（剑/弩/枪）、防具（盾/防滑鞋等）及个人 5 槽词条（投掷/连发/震荡波等）基于 GAS 与 `DataAsset` / `DataTable` 的动态变形生命周期。
- **FPS 机关、防晕与可读性同步**：10 大非数值机关（100% 敌我不分、次数耗尽与回合重装、`Roll=0` 纯速度向量防晕、0.3s 声光前摇、损友归因标牌）与服务器权威结算。
- **1v1 / 2~4P 离散回合状态机与网络同步**：Listen Server 多人联机、战备顺序一键热切开关（先放陷阱 vs 先构筑）、1v1 BO3 / 2v2 / 4P 10 分（含机关助攻分）、击杀重置状态反渔翁、中央大喇叭与两段式流血缩圈、多人观战幽灵。
